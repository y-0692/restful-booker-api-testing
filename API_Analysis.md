# Restful Booker API Testing

QA portfolio project demonstrating API testing using Postman.

## Project Overview

This project covers end-to-end API testing of the Restful Booker application.

## APIs Tested

### Authentication
- Create Token

### Booking
- Create Booking
- Get Booking
- Update Booking
- Delete Booking

## Test Coverage

### Positive Test Cases
- Valid authentication
- Create booking successfully
- Retrieve booking details
- Update booking successfully
- Delete booking successfully

### Negative Test Cases
- Create booking with missing required fields
- Invalid authentication
- Unauthorized update request
- Unauthorized delete request

## Validation Performed

- Status code validation
- Response body validation
- Data type validation
- Required field validation
- Token generation validation
- Booking ID validation

## Tools Used

- Postman
- REST API
- JSON
- GitHub
