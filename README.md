# Restful Booker API Testing

QA portfolio project demonstrating REST API testing using Postman.

## Project Scope

This project covers:

- Authentication API testing
- Create Booking
- Get Booking
- Update Booking
- Delete Booking
- Positive test scenarios
- Negative test scenarios
- Response validation using Postman scripts
- Variable management using collection variables

## Tools Used

- Postman
- REST API
- GitHub

## Test Coverage

### Authentication
- Generate authentication token
- Validate token exists

### Booking APIs
- Create booking
- Retrieve booking details
- Update booking information
- Delete booking

### Negative Testing
- Missing required fields
- Invalid request data
- Unauthorized access
